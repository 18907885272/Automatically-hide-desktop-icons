# 自动隐藏桌面图标

> 版本: v2.2

轻量级 Windows 工具，通过系统托盘图标快速切换桌面图标的显示/隐藏状态，同时自动最小化或恢复所有应用窗口，支持快捷键、双击检测等多种方式，帮助您快速清理桌面或专注工作。

---

## 主要功能

- **托盘图标左键单击**：切换桌面图标的显示/隐藏状态，显示图标时最小化所有应用窗口，隐藏图标时不恢复窗口
- **托盘图标右键菜单**：包含"设置"和"退出"选项
- **快捷键切换**：Ctrl + 空格 切换桌面图标显示/隐藏（可配置，修饰键正常释放）
- **快捷键退出**：Ctrl + Shift + Q 退出程序（可配置，修饰键正常释放）
- **双击检测**：双击桌面或任务栏空白处可切换图标显示/隐藏（可独立控制），双击桌面图标不会触发
- **空闲超时**：长时间无操作自动隐藏桌面图标
- **设置窗口**：Win32 原生窗口，所有参数可配置
- **关屏快捷键**：Ctrl + Alt + 向下箭头 一键关闭显示器（带防误唤醒保护）

## 使用方法

### 1. 启动程序

双击运行 `自动隐藏桌面图标.exe`，程序会在系统托盘区域显示图标。托盘图标会根据桌面图标状态自动切换（显示状态/隐藏状态）。

### 2. 切换桌面图标

- **左键单击托盘图标**：立即切换桌面图标的显示/隐藏状态，显示图标时自动最小化所有应用窗口，隐藏图标时不恢复窗口
- **快捷键**：按下 Ctrl + 空格 切换桌面图标显示/隐藏（修饰键正常释放，不卡键）
- **双击桌面空白处**：双击桌面空白区域可切换图标显示/隐藏（受设置控制）
- **双击任务栏空白处**：双击任务栏空白区域可切换图标显示/隐藏（受设置控制）

### 3. 窗口联动行为

- **显示桌面图标时**：自动**最小化**所有当前可见的应用程序窗口，快速回到桌面
- **隐藏桌面图标时**：**不恢复**应用窗口，原来已最小化的窗口保持最小化状态
- 桌面和任务栏不会被最小化

### 4. 设置菜单

右键单击托盘图标，选择"设置"可打开设置窗口，配置所有参数。

### 5. 退出程序

- **托盘菜单**：右键单击托盘图标 -> "退出"
- **快捷键**：按下 Ctrl + Shift + Q 退出程序

## 托盘图标说明

- **桌面图标显示状态**：托盘图标显示为 `1.png`
- **桌面图标隐藏状态**：托盘图标显示为 `2.png`
- 图标文件已内嵌到 EXE 中，无需额外放置文件

## 配置参数说明

| 参数 | 默认值 | 作用说明 |
|------|--------|----------|
| `toggle_hotkey` | ctrl+space | **切换快捷键**。按下 Ctrl + 空格 时切换桌面图标：显示图标时最小化所有应用窗口，隐藏图标时不恢复窗口。 |
| `toggle_enabled` | true | **启用切换快捷键**。设置为 true 时 `toggle_hotkey` 生效，false 时该快捷键无效。 |
| `exit_hotkey` | ctrl+shift+q | **退出快捷键**。按下 Ctrl + Shift + Q 时退出程序。 |
| `exit_enabled` | true | **启用退出快捷键**。设置为 true 时 `exit_hotkey` 生效，false 时该快捷键无效。 |
| `monitor_hotkey` | ctrl+alt+down | **关屏快捷键**。按下 Ctrl + Alt + 向下箭头 时关闭显示器（屏幕变黑），关屏后带 3 秒防误唤醒保护，期间松开按键/移动鼠标不会点亮屏幕，之后动鼠标即可唤醒。修饰键正常释放，不会卡键。 |
| `monitor_enabled` | true | **启用关屏快捷键**。设置为 true 时 `monitor_hotkey` 生效，false 时该快捷键无效。 |
| `dblclick_desktop_enabled` | true | **启用桌面双击切换**。设置为 true 时，双击桌面空白处会切换桌面图标显示/隐藏。设置为 false 时，双击桌面空白处不触发。 |
| `dblclick_taskbar_enabled` | true | **启用任务栏双击切换**。设置为 true 时，双击任务栏空白处会切换桌面图标显示/隐藏。设置为 false 时，双击任务栏空白处不触发。 |
| `idle_hide_timeout` | 60 | **空闲超时**（单位：秒）。设置为 0 时禁用空闲自动隐藏；设置为 60 时，如果用户 60 秒没有操作，会自动隐藏桌面图标。 |

> **使用建议：**
> - 将 `idle_hide_timeout` 设置为 0 可禁用空闲自动隐藏功能
> - 如果不需要双击切换，可设置 `dblclick_desktop_enabled` 和 `dblclick_taskbar_enabled` 为 false
> - 三个快捷键（切换/退出/关屏）都可在设置窗口或 `config.json` 中修改，支持 ctrl/shift/alt/win 修饰键与 space、字母、数字、F1-F12、方向键等主键
> - 修改 `config.json` 后需重启程序生效；快捷键可能与其他软件冲突，建议避开 Ctrl+Alt+方向键（显卡驱动的屏幕旋转快捷键）

## 常见问题

> **注意事项：**
> - 程序启动后会常驻系统托盘，右键菜单可退出
> - 切换桌面图标时会联动最小化所有应用窗口（隐藏图标时不恢复窗口）
> - 双击检测需要在桌面或任务栏空白处点击，不要点在图标或按钮上
> - 双击桌面图标或应用窗口不会触发切换
> - 程序退出时会自动显示桌面图标，不干扰窗口状态

## 技术特点

- 纯 Go 语言编写，无外部依赖，轻量高效
- 使用 Win32 API 实现低层钩子和窗口管理
- 支持动态托盘图标切换（显示/隐藏状态不同图标）
- 图标文件已内嵌到 EXE 中，无需额外放置文件
- 配置文件 `config.json` 可手动编辑（UTF-8 编码）
- 版本号：v2.2
